## Diseño y límites

C06-02 conserva intacta su semántica no autorizante (migración 019, propuestas y auditoría). No convertir propuestas en grants. El primer corte implementa una decisión pura de asignar o revocar una capacidad existente `identity.private.read` sobre **un recurso y sucursal exactos**. Propietario o administrador verificados necesitan techo explícito vigente, no basta su rol. No se otorga capacidad de delegación a destinatarios ni se eleva a propietario, administrador o plataforma. La acción normativa `cases.read`, administración de roles, finanzas, media, privacidad y demás acciones aún no activadas siguen sin nuevas rutas ni grants. Roles configurables genéricos, catálogo editable y editor son trabajo restante.

La política consume identidad C06-03 del mismo reloj de transacción, objeto/tenant/sucursal/acción exactos del servidor, estado de recurso, condición comercial verificada, membresía destino, rol destino y revisión, techo del actor, step-up ligado al comando completo y grant existente con revisión esperada. Deniega por defecto; una asignación no extiende el techo o la membresía ni sobreescribe/reactiva filas. Revocación exige grant exacto no revocado y no crea registros. Un resultado solo indica comando y revisión esperada/nueva; **no autoriza lectura ni sustituye C06CaseAbacPolicy**. Ninguna autoridad se adquiere al construir una clase desde un request.

Probar replay, carrera y rollback reales. Los campos de evidencia de dominio no demuestran por sí solos la validez criptográfica, la existencia de filas ni el consumo de MFA.
3. Conectar solo con políticas de lectura efectiva ya revisadas y nuevo catálogo versionado, no aceptar un grant delegado como autorización autónoma. El adapter debe comprobar propiedad/asignación y política ABAC vigente; no dar permisos a otra acción/sucursal/recurso. Revocación inmediata API y UI sin depender de un cache o token antiguo. Una condición comercial suspendida impide acceso; invalidación administrativa/automática debe tener su flujo independiente seguro. El corte actual no expone ninguna operación.
4. API cerrada, DTO mínimo y neutral; actualizar inventario y proyección/negativas con cobertura de nuevas rutas antes de exponer. Editor accesible con revisión de alcance y MFA; nueva calidad individual >=9.5. No construir UI que afirme operaciones que backend todavía no ofrece.
