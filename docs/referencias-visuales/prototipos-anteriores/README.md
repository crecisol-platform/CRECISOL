# Prototipos anteriores: evolución histórica de CRECISOL

Carpeta para conservar **el último prototipo y el penúltimo**, o cualquier otro prototipo propio que ayude a identificar ideas visuales, pantallas y flujos que merezca la pena evaluar.

## Formatos útiles
- Capturas PNG/JPG de pantallas completas, menús, tablas, formularios y diseños responsive.
- Archivos HTML/CSS/JS o ZIP de **prototipos propios de CRECISOL**, solo como material de estudio, nunca como dependencia ejecutable.
- Notas de qué versión te gustó más y qué decisiones deberíamos revisar.

## Reglas
- **No ejecutar** archivos ni scripts de prototipos recibidos sin revisión y autorización.
- **No copiar código legado** directamente a los módulos nuevos; implementación limpia y verificada desde cero.
- No incluir `.env`, contraseñas, conexiones, código ni datos privados de SOLQARYN o de terceros.
- Si alguna imagen o archivo es ajeno, conservar la atribución y comprobar que existe autorización para su uso.

Para cargar: GitHub → carpeta en `dev` → **Add file → Upload files** → seleccionar archivos → **Commit changes**.

**Estado inicial:** sin prototipos cargados por el usuario.
