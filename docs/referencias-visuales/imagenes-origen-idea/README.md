# Imágenes: cómo nació la idea de CRECISOL

Esta carpeta conserva **capturas de pantalla, bocetos e imágenes de inspiración** aportados por el propietario, para estudiar navegación, paneles, formularios, tablas, distribución visual, iconografía y experiencia de uso.

**No son especificaciones obligatorias ni pantallas finales.** La interfaz se diseñará y programará desde cero bajo el Documento Maestro Único y el sistema visual oficial de CRECISOL.

## Para cargar imágenes
En GitHub, abrir esta carpeta en `dev`, elegir **Add file → Upload files**, arrastrar los PNG, JPG, WEBP o demás imágenes autorizadas y guardar mediante **Commit changes**. Mantener una nomenclatura descriptiva, por ejemplo `panel-comercial-01.png` o `formulario-referencia-02.jpg`.

No subir datos personales reales, contraseñas, credenciales, datos de otros proyectos ni material que no se tenga autorización para conservar.

**Estado inicial:** sin imágenes cargadas por el usuario.
