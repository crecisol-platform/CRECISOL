# Database CRECISOL

Área reservada para MySQL 8.4 LTS InnoDB, normalización relacional, FK/UNIQUE por tenant, migraciones reversibles, catálogo de DB compartidas o dedicadas, seeds sintéticos y pruebas de backup/restore.

Una sola solución de código con distintos modos de aislamiento. No se ha creado ninguna base ni ejecutado SQL.
